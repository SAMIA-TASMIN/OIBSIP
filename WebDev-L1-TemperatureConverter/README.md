# Thermo — Temperature Converter

Oasis Infobyte Web Development & Designing Internship — Level 1, Task 3.

## Features
- Converts Celsius, Fahrenheit, and Kelvin
- Numeric input validation and clear errors
- Absolute-zero validation in all three input scales
- Displays all converted scales at once
- Responsive centered interface
- Vanilla JavaScript; no dependencies

## Run
Open `index.html` in a modern browser.

## Formula
Convert input to Celsius first, then derive Fahrenheit (`C × 9/5 + 32`) and Kelvin (`C + 273.15`).
