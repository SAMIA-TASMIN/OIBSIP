# Oasis Infobyte Web Development & Designing — Level 1

This bundle contains all three Level 1 projects. Copy the three project folders into your existing `OIBSIP` repository.

- `WebDev-L1-LandingPage/` — HTML/CSS landing page (LUMORA concept brand)
- `WebDev-L1-PersonalPortfolio/` — your existing React/Vite portfolio cleaned of `.git` and `node_modules`, with the supplied professional headshot included
- `WebDev-L1-TemperatureConverter/` — HTML/CSS/Vanilla JS temperature converter

Before submission: test each project, capture screenshots, update any personal data or placeholders, push all folders to GitHub, record a demo, post the demo to LinkedIn tagging @Oasis Infobyte and using #oasisinfobyte, and submit the form.
