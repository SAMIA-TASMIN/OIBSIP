# LUMORA Landing Page — Oasis Infobyte Level 1 Task 1

Responsive concept landing page for a fictional furniture brand. Built with semantic HTML5 and CSS3 only.

## Features
- Sticky navigation with anchor links
- Hero section and CTA
- Product collection and brand story sections
- Contact/social footer
- Responsive Flexbox/Grid layouts and mobile breakpoints
- Consistent palette, typography, hover states, and accessible link labels

## Run
Open `index.html` in a modern browser. Google Fonts are loaded online; fallback fonts are included.

## Note
LUMORA is a fictional concept brand; contact/social links are placeholders.


## Local image assets

All furniture photographs are stored in the `assets/` folder and referenced with relative paths, so they load when the project is opened locally or deployed with the complete folder.

- `assets/haven-chair.webp` — hero and lounge chair
- `assets/forma-dining-table.png` — dining table collection card
- `assets/solace-sofa.jpeg` — sofa collection card
- `assets/lumora-showcase.jpeg` — brand story image
